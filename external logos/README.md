# External logos

Downloaded brand assets for the Collie website and desktop app. Every asset is
an SVG so it remains transparent and resolution-independent; no generated
artwork is included.

## Provenance

- Most files come from the [Simple Icons](https://github.com/simple-icons/simple-icons)
  SVG collection, downloaded from its CDN on 2026-08-01. Simple Icons publishes
  the corresponding brand source/guideline links in its icon data and asks users
  to review its [disclaimer](https://github.com/simple-icons/simple-icons/blob/develop/DISCLAIMER.md).
- `groq.svg` comes from Groq's official [Powered by Groq badge](https://console.groq.com/docs/badge).
- `microsoft-copilot.svg` comes from Microsoft's official
  [Power Platform SVG icon package](https://learn.microsoft.com/en-us/power-platform/guidance/icons).
- `chatgpt.svg` uses the OpenAI knot mark from `openai.svg`, which is the mark
  used by ChatGPT; it is duplicated under the product-facing filename for
  straightforward asset lookup.

The Microsoft icon package has usage terms on Microsoft's documentation page.
Review those terms before publishing the Copilot asset in a context beyond the
website/app UI.

## Coverage

The folder covers the union of the visible logo references found in both
products:

- Website intelligence: ChatGPT, Claude, Gemini, Copilot, Perplexity,
  DeepSeek.
- Website Microsoft 365: Word, Excel, PowerPoint, Outlook, Teams, OneDrive.
- Website Google Workspace: Gmail, Calendar, Docs, Sheets, Drive, Meet.
- Website tools/community: Notion, Canva, Slack, Trello, Zoom, Figma, GitHub,
  Airtable, Dropbox, Linear, Shopify, Discord.
- App model providers: OpenAI/ChatGPT, Anthropic/Claude, DeepSeek, OpenRouter,
  Groq, Ollama.
- App connectors: Notion, Linear, Todoist, Atlassian, Gmail, Google Calendar,
  Google Drive, Google Sheets, Outlook, OneDrive, Slack, Dropbox, Airtable,
  GitHub.
- App messengers: Telegram, WhatsApp, Slack, Discord.

These are collected source assets in one shared folder; existing UI references
were intentionally left unchanged by this asset-collection task.
