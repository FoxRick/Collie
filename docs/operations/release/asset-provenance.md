## Third-party marks

`collie-ui/src/renderer/src/assets/providers/` contains third-party provider
and service logos (OpenAI, Anthropic, DeepSeek, Google, etc.). They are not
Collie-owned branding and no permission to reuse them is granted through this
repository. Records per the clearance requirements:

1. **Paths + hashes:** every file in the providers directory is in
   `asset-provenance.sha256`.
2. **Source:** official brand logo files (SVG/PNG) downloaded from the
   brands' official sources and mark registries during 2026-07/08
   (see the website's logo-sourcing record for the same sourcing recipe);
   no image generation or unofficial third-party providers were used.
3. **Basis:** nominative identification only — they identify which providers
   Collie can connect to. No affiliation, partnership, endorsement, or
   current-availability implication is intended or granted.
4. **Use:** in-app provider pickers and the website only, at the sizes
   required for identification, subject to each owner's trademark and
   brand-guideline restrictions. Not redistributable as standalone assets.
   **Cleared for installer inclusion on this nominative-use basis.**
