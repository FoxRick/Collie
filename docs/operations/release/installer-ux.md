# Windows setup experience

**Status:** implemented on `feat/installer-ux`; alpha, not yet published

The Windows package uses electron-builder's NSIS target in **assisted** mode
with a custom include (`collie-ui/build/installer.nsh`). The result is a
short, friendly wizard a nontechnical person can run without fear - no
administrator prompt, no jargon, one checkbox, and a warm finish.

## Page flow

Fresh install (per-user):

1. **Welcome** - app branding (header image) and one warm line: "Collie is
   your personal AI - free, open source (MIT), no account needed."
2. **Install mode** - Recommended ("Set up Collie for me", no administrator
   password needed) vs Custom ("Choose where to put Collie").
3. **Location** - only when Custom was chosen; friendly default
   `%LOCALAPPDATA%\Programs\Collie`.
4. **Shortcuts** - one checkbox: "Add Collie to my desktop", default ON.
5. **Progress** - standard install-files page.
6. **Finish** - "Start Collie now" checked by default, warm closing line.

Updates skip pages 2-4 (the install location and shortcut preference from the
original setup are kept).

## Decisions

- **Per-user install (`perMachine: false`)** - no UAC/admin elevation, so the
  wizard never asks for a password. The template's per-machine mode page is
  skipped via the `customInstallMode` hook.
- **Single language** - English only (`installerLanguages: [en_US]`, default
  LCID 1033). No language dialog.
- **No license page** - MIT is permissive; the license is one small line on
  Welcome instead.
- **No bundled extras or offers** - the wizard ships nothing but Collie.
- **Lightweight** - NSIS default compression, one 150x57 header bitmap, no
  side images. The installer grows by roughly the size of that bitmap
  (tens of KB) versus the previous one-click configuration.
- **Voice rules (PR #19)** - copy is a warm friendly person; never dog-voiced
  text, never jargon ("installer", "binary", "PATH" do not appear). The dog
  stays in visuals only.

## Config surface

- `collie-ui/electron-builder.yml` - `nsis:` block: `oneClick: false`,
  `perMachine: false`, `allowToChangeInstallationDirectory: true`,
  `installerLanguages: [en_US]`, `include: build/installer.nsh`.
- `collie-ui/build/installer.nsh` - page hooks (`customWelcomePage`,
  `customPageAfterChangeDir`, `customFinishPage`, `customInstallMode`) and the
  warm copy.
- `collie-ui/build/installer-header.bmp` - 150x57 24-bit header image,
  regenerated by `npm run installer-header:generate`
  (`collie-ui/scripts/generate-installer-header.cjs`).
- `.github/workflows/installer-build.yml` - builds the Windows installer on a
  `windows-latest` runner whenever installer config/assets, main-process or
  preload code, or workflow files change; runs typecheck + vitest first and
  uploads `Collie-Setup-<version>.exe` (+ `.blockmap`, `alpha.yml` - the
  updater metadata for the alpha channel) as a workflow artifact. The Linux
  VM cannot build the Windows target (wine + NSIS are required), so CI is the
  verification path.

## Verification

1. `collie-ui` -> `npm ci`, `npm run build`.
2. `collie-core` -> `python -m venv .venv`, `.venv\Scripts\pip install -e .`
3. `collie-ui` -> `npm run stage:core` (stages the bundled Python core).
4. `collie-ui` -> `npx electron-builder --win nsis --x64 --publish never`.
5. Install the produced `dist/Collie-Setup-<version>.exe` on a clean Windows
   profile and walk all five pages; verify no UAC prompt appears and that
   unchecking the desktop checkbox leaves no desktop icon after install.
